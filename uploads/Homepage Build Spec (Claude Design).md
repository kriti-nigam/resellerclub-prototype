# Homepage Build Spec (Claude Design)

Build-ready spec for the ResellerClub homepage first cut. Pair with [[Positioning Brief]] for messaging and with Mukhtadir's existing design system for visual style. This is content and structure, not final visual design.

## Positioning in one line

ResellerClub is the wholesale domain registrar built for the businesses that put others online: web hosts, developers and agencies, and AI and website-builder platforms.

## Tone and voice

Direct and concise. No buzzwords. No em-dashes. No emojis. Confident, not salesy. Speak to a reseller or builder, not an end consumer. Domains lead; hosting does not.

## Global navigation

- Products: Domains, Email (Titan, Google Workspace), SSL certificates, Hosting, DNS and Premium DNS, Security add-ons, Website builder.
- Platform and Developers: API overview, Documentation, MCP and agents, Sandbox, Integrations (WHMCS, Plesk), Storefront (Supersite), Control panel.
- Who it's for: Web hosts, Developers and agencies, AI and website-builder platforms.
- Pricing (transparent tiers).
- Resources: Docs, Help center, Blog, Case studies, Status.
- Right side: Sign in, and a primary button, Become a reseller.

## Homepage sections (in order)

### 1. Hero
- Headline: "The wholesale domain registrar built for the people who build the web."
- Subhead: names the three audiences. Draft: "For web hosts, developers and agencies, and AI and website-builder platforms."
- Primary CTA: Become a reseller. Secondary CTA: Explore the API.
- No domain search box. This is a lead-gen page, not a retail storefront.

### 2. Reseller logo wall (social proof)
- Heading direction: "Trusted by resellers worldwide."
- Real, current reseller or customer logos only. Assets to be supplied with permission.

### 3. Proof strip (scale)
- 20+ years as a domain reseller platform. 100+ ICANN-accredited registrars on OrderBox. Domain count and TLD count to confirm [TBD].

### 4. Why ResellerClub (four pillar cards)
1. Wholesale, by heritage. Reseller-first pricing and control, white-label, registrar backbone run for you, so you scale without becoming a registrar.
2. Built for builders. Modern API, clean docs, agent and MCP ready. Provision domains directly on the front of your own site or app.
3. Everything your customers need. Domains first, then email, SSL, and hosting, under one account.
4. Support built for partners. 24/7 help, dedicated account management, migration and onboarding, technical and API support.

### 5. Product ecosystem (domains-led)
- Lead with Domains. Then Email, SSL, Hosting, with DNS and Premium DNS, security add-ons, and website builder as supporting.
- Transparent "from" pricing teasers that link to the Pricing page.

### 6. Built for builders (deeper block)
- API, MCP and agents, sandbox, integrations (WHMCS, Plesk). Provision in your own workflow.
- CTA: Explore the API.
- Guardrail: agent and MCP readiness claims appear only when the OrderBox API Refresh items ship. Do not present them as roadmap.

### 7. Who it's for (three equal tiles, link to segment pages)
- Web hosts: bundle domains, email, and SSL with your hosting; margin and white-label control.
- Developers and agencies: provision and manage domains for client sites fast, by panel or API.
- AI and website-builder platforms: embed domain registration into your build flow; API and MCP ready.

### 8. Ways to sell
- Storefront (Supersite), Control panel, API, Integrations. One line each.

### 9. Pricing snapshot
- Transparent wholesale tiers, volume-based. Link to the full Pricing page.

### 10. Support
- 24/7, dedicated account management, migration and onboarding, technical and API support.

### 11. Closing CTA
- Primary: Become a reseller. Secondary: Explore the API.

### Footer
- Columns mirroring nav: Products, Platform and Developers, Who it's for, Pricing, Resources, Company, plus legal and sign-in.

## Assets and open items to supply

- Reseller logos cleared for use.
- Confirmed scale numbers: domains under management, TLD count, reseller count.
- Design system reference (colors, type, components).
- Primary success measure for the page: qualified leads and partnerships.

# Portal UI kit

A high-fidelity recreation of the **ResellerClub Developer Portal** — the marketing-meets-docs surface developers land on.

- `index.html` — single self-contained screen: sticky top nav + logo lockup, split hero with a live-looking code panel, a proof/stat strip, and a Domains API reference list. Links the root `styles.css` and loads Lucide from CDN.

It composes the same visual language as the design-system primitives (`Button`, `Badge`, `MethodTag`, `Logo`, `Code`). The fully interactive version (command palette, docs router, dashboard, onboarding) lives in the separate **ResellerClub** prototype project — this kit is the brand-accurate static reference.

Thin-stroke Lucide icon — use for every icon in the system (no emoji, no unicode glyphs).

```jsx
<Icon name="arrow-right" size={16} color="var(--rc-accent)" />
```

Load `<script src="https://unpkg.com/lucide@latest"></script>` once, then call `lucide.createIcons()` after render. Default stroke width is 2; rounded caps match the brand.

Primary call-to-action button. Use `primary` for the single main action in a view; `secondary`/`ghost` for lower-emphasis actions; `dark` on light proof sections; `onDark`/`accentSoft` inside dark or tinted panels.

```jsx
<Button variant="primary" iconRight="arrow-right">Get API keys</Button>
<Button variant="secondary" icon="book-open">Read the docs</Button>
```

Sizes: `sm` / `md` (default) / `lg`. Primary lifts a blue glow on hover and darkens on press — never scales. Pass `href` to render an anchor.
